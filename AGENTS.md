# AGENTS.md — joannamyers.org

Guidance for AI coding agents working in this repository.

## What this is

The personal blog **"Colours of my life"** of **Joanna Myers** (joannamyers.org),
about Christian living, health, parenting, family and overcoming challenges.
It was migrated from Blogger in 2026 and is maintained by her husband Chris
(GitHub account `cwmyers`). All 37 Blogger posts live here; the original
Blogger post URLs (`/YYYY/MM/slug.html`) are preserved exactly.

## Tech stack

- **Static site generator:** Eleventy (v3), config in `eleventy.config.js` (ESM)
- **Templating:** Nunjucks (`.njk`), markdown files processed with njk engine
- **Styling:** hand-written vanilla CSS in `src/css/style.css` — no framework
- **Fonts:** Google Fonts — Damion (script accents), Playfair Display (headings), Source Serif 4 (body)
- **Publishing UI:** Decap CMS served from `/admin/` (`src/admin/`), GitHub backend with PKCE auth — lets the owner publish from an iPad
- **Hosting:** GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`); public repo `cwmyers/joannamyers.org`
- **Analytics:** Google Analytics 4, property `G-CG83VJCL75` (inherited from Blogger) — snippet lives in `src/_includes/base.njk`
- **Feed:** Atom RSS hand-templated in `src/feed.njk` → `/feed.xml`

## Commands

```bash
npm install     # once
npm run dev     # dev server with live reload at http://localhost:8080/joannamyers.org/
npm run build   # build to _site/
```

Deploy = `git push` to `main`. The GitHub Action builds and publishes; there is
no other deploy step.

## Structure

```
src/
  posts/                  # blog posts (files named YYYY/MM/slug.html)
  posts/posts.11tydata.js # default layout + permalink rule for posts
  images/                 # site images (e.g. portrait.jpeg)
  admin/                  # Decap CMS (index.html + config.yml)
  _includes/              # base.njk, post.njk, about.njk templates
  css/style.css           # all styling
  index.njk               # homepage (hero + latest posts)
  archive.njk             # archive grouped by year
  about.md                # about page (CMS-editable, uses about.njk layout)
  feed.njk                # Atom feed
  404.njk, CNAME, favicon.svg
scripts/migrate-blogger.py  # one-time Blogger migration (idempotent, regenerates src/posts from the Atom feed)
```

## Important conventions / gotchas

- **pathPrefix:** `eleventy.config.js` sets `pathPrefix: "/joannamyers.org/"`
  because the site is served from the GitHub Pages project URL
  `https://cwmyers.github.io/joannamyers.org/`. All internal links must go
  through Eleventy's `url` filter (`{{ "/archive/" | url }}`). When the custom
  domain goes live, change `pathPrefix` to `"/"` and re-add the `CNAME` file
  (content: `www.joannamyers.org`).
- **Post URLs** follow the Blogger pattern `/YYYY/MM/slug.html`. New posts get
  this automatically via `eleventyComputed.permalink` in `posts.11tydata.js`.
  Don't change this — old links must keep working.
- **Post descriptions** (~300-char previews shown on the homepage) are
  auto-generated by the migration script. Posts without a description fall
  back to an auto-excerpt via the `excerpt` filter in `eleventy.config.js`.
- `package.json` uses `"type": "module"` — data files and config must be ESM.
- Collections are piped through the `newestFirst` filter where order matters
  (homepage, feed, archive, prev/next nav).
- The design language: warm cream background (`#faf7f2`), terracotta accent
  (`#9d4b3c`), deep teal sidebar (`#3a6363→#2c4d4d` gradient), gold details.
  Keep new UI consistent with this palette.

## Content workflow (the owner's)

Joanna publishes via `joannamyers.org/admin/` (Decap CMS) from her iPad;
posts are `.md` files created in `src/posts/`. Editing posts programmatically
is fine, but never break the CMS config (`src/admin/config.yml`) — she relies
on it for publishing.
